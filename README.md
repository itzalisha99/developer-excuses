A make.fun entry for **Make the AI Judge Laugh: Developer Excuses**: one funny
single-line excuse a developer gives when code breaks in production, under 200
characters.

## The excuse

> It passed every test. All three of them. I wrote two.

## How it works

`main.py` (Python stdlib only, deterministic) writes the excuse to
`/output/entry.txt`. It validates the text against the bounty gate first:
1–200 characters, UTF-8, a single line, not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
